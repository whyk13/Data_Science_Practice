第9讲 SVM 与 Margin
PBL Flipped Classroom Teacher Plan
面向生命科学学院大四直博生。目标是让学生通过证据理解 SVM 边界，并为脊柱研究组选择一个离线基线。学生已修微积分、数理统计和前八讲；向量、内积和长度在学习单中就地解释，不要求凸优化基础。
时间：课堂启动45分钟、课外自学约135分钟、翻转课堂45分钟。学习单是唯一必做载体；Notebook 为辅助复现；review/ 内的试填答案不得发给学生。
目标覆盖
LO1（总纲：找到一个分类超平面；什么是 margin？）：写出线性得分 f(x)=wᵀx+b，说明分类超平面 f(x)=0 的含义，并计算样本到超平面的几何距离。 对应 Q1。
LO2（总纲：为什么最大化 margin 有助于泛化？margin 越大，模型对扰动越稳健）：用几何间隔解释“最大化间隔为什么可能有助于泛化”，并说明它只保护已有样本免受小扰动，不保证新样本的准确率。 对应 Q1、Q6。
LO3（总纲：Support vectors：决定分类边界的关键样本）：从移除试验和边界图中识别支持向量，说明为什么只有支持向量决定边界。 对应 Q2。
LO4（总纲：Soft margin：允许少量分类错误；通过参数 C 控制误差和 margin 的权衡）：计算合页损失，区分间隔违例与分类错误，用证据说明 C 怎样在间隔宽度与违例之间权衡。 对应 Q3、Q5。
LO5（总纲：kernel trick 是什么？linear kernel；polynomial kernel；RBF kernel）：用内积与特征映射解释核技巧，比较线性、多项式和 RBF 核的边界，区分 gamma 与 C 的作用。 对应 Q4。
LO6（总纲：参数敏感）：在训练内标准化、验证选参、测试隔离的流程中说明参数敏感，并冻结一个可复现的方案。 对应 Q5。
LO7（总纲：适合中小样本；在高维数据中表现好；大数据上训练慢；可解释性有限）：判断 SVM 在中小样本、高维和大样本研究中的适用性，并说明它的可解释性局限。 对应 Q6。
LO8（总纲：作业 用自己的话解释：为什么 SVM 不是简单地找一条“刚好分开两类”的线？）：用自己的话解释“为什么 SVM 不是简单地找一条‘刚好分开两类’的线”（本讲作业原题）。 对应 Q6。

Q1：线 a 的最近样本为 N2、N3、P1，最小 |f|=1、‖w‖=1、最小距离1；线 b 的最近样本为 P1，最小 |f|=0.2、最小距离0.2；5u 重写后最小 |f|=5、‖w‖=5，最小距离仍为1。长度小于0.3的扰动不会让线 a 判错任何样本，但可让线 b 判错 P1。脊柱变量原始范围差异很大且单位未注明，同一欧氏长度对不同变量含义不同；几何保障只针对已有点，不是新样本误差界。
Q2：①间隔线 u=−1 与 u=1，支持向量为 N2、N3、P1；②移除 N1（远点、非支持向量）边界仍为 u=0、带宽2；移除 P1 后边界移到 u=1、带宽4；③移除 P2 预测不变，核对结果边界 u=0.000、带宽2.000。支持向量是样本不是特征，也不是“典型病例”。T2 的担忧信号：支持向量数接近训练集全部（表 C3 中有两行为186/186）。
Q3：合页损失依次为0、0.6、1.2、2.0；0.4 判对但违例，−0.2 与 −1.0 判错且违例。表 B2：C=0.01 带宽3.655、违例66、支持向量68、验证判对22/24；C=100 带宽1.397、违例21、支持向量23、验证判对21/24。C 变小时带宽变宽、带内点与支持向量增多。两者只差1个验证点，24点无法支撑“C 越小越好”，更不能外推到六维脊柱数据——这正是 Q5 表 C3 要检验的。允许学生在 T3 暂写“偏好较小 C”，Q5 应修正。
Q4：xᵀz=2，K=4；φ(x)=(1, 2√2, 4)，φ(z)=(4, 0, 0)，φ(x)ᵀφ(z)=4。这是 r=0、gamma=1 的二次核算例，图 C1 使用 r=1，两者不能混算。距离1时 gamma=0.1 的相似度约0.905，gamma=10 约4.54×10⁻⁵。gamma 控制每个样本的影响范围（边界的弯曲程度），C 控制违例的代价。三核比较中“不能推出”的合格答案包括：不能推出脊柱数据也是弯曲结构；24个验证点上相差2个点不足以排名；RBF 训练错误少不等于泛化好。
Q5：①未标准化：支持向量186/186、训练平衡准确率1.000、验证0.500（全部判为异常）；已标准化：92、0.848、0.767。原因：滑脱程度的范围（约430）远大于其他变量，原始距离几乎只由它决定，gamma=0.1 时验证记录与所有训练记录都“不相似”，模型退化为记忆训练点。②线性 C=0.01 带宽6.69最宽，但验证平衡准确率0.500、正常召回0/20——全部判为异常；C=10 带宽0.35、验证0.789。宽带宽不是选择标准，C 必须由验证决定。③gamma=10：训练0.992、验证0.525、支持向量186/186，图 C2 中 gamma=10 一行验证在0.525–0.600。④合格条件：L 与 R 通过（L 的正常召回恰为13/20=0.650，处在门槛上）；P 的正常召回12/20=0.600 未通过。
T5 可接受的答案：L（C=10）——与 R 验证几乎相同（相差0.001），更简单、支持向量更少（56 对 94）、便于与逻辑回归并列说明；R（C=10、gamma=0.01）——正常召回14/20 比 L 多一条，离门槛更远；D——须指出具体的证据缺口（如验证正常类只有20条，L 恰在门槛上），不能只说“不是临床数据”。不接受 P 或“看测试再定”。
Q6：以 L 为例，异常召回 38/42=0.905，正常召回 15/20=0.750，满足合格条件；R 为 39/42、15/20。图 D1 在20%噪声时（平均平衡准确率/翻转比例）：线性 0.825/0.021，RBF 0.815/0.035，二次多项式 0.784/0.022。平均表现问“整体判对多少”，翻转比例问“多少记录的预测随小扰动改变”，前者可在翻转互相抵消时保持不变。正常只有20条，一条改变5个百分点，不宜把 L 与 R 的测试差距解释为普遍优势；测试后想换核，需要新的独立测试。80×2000：可以尝试线性核并严格验证，p≫n 时训练集往往可分但未必泛化，支持向量是样本而非基因，不能直接当生物标志物；100000×6：完整核矩阵约80 GB，核 SVM 训练代价大，宜用线性专用求解器，该任务关注复现与速度，可解释性不是首要问题。
概念辨析参考：①SVM 得分只用符号分类，数值没有概率刻度，逻辑回归输出概率（仍需校准）；混淆会把得分当风险直接比较或设阈值。②线性带宽是标准化空间的几何宽度，RBF 的 f=±1 是隐式空间在原始平面上的等高线，不能用尺子比较；混淆会误判“RBF 间隔更窄/更宽”。③验证集用于选参与冻结，测试集只评估冻结方案；混淆会导致测试泄漏与过乐观报告。
可用追问：为何要除以权重长度？判对为何仍有损失？支持向量能否当特征？改变单位时 gamma 是否仍是同一种设置？RBF 虚线为何不能用尺量出与线性相同含义的间隔？为什么线性 C=0.01 最宽却最差？高 p 与大 n 为什么是不同的问题？测试结束后若想换核，需要什么新的评估？
