## 五、决策检查

- **学生能否在最后作出承诺？** 能。试填路径如下：
  1. T0 依据表 S1 的“比较计划”与 n、p 选 L。
  2. T1–T4 逐步建立“大间隔、支持向量、C 与核”的判断，T3 暂时写下“验证相近时偏好较小的 C”。
  3. Q5 用表 C3 修正了 T3：线性 C=0.01 带宽最宽，却把验证记录全判为异常。表 C2 显示 P 的正常召回 12/20 不合格；L 与 R 都合格，验证平衡准确率 0.789 对 0.790。
  4. T5 以“支持向量更少（56对94）、便于说明、可与逻辑回归并列”为由冻结 L（C=10）。
  5. T6 用表 D1 的 38/42、15/20 保留 L。
- **其他同样可辩护的路径：**
  - 选 R，理由是正常召回 14/20 离门槛更远；
  - 选 D，但必须指出具体缺口，例如验证正常类只有20条、L 恰好在门槛上。
- **被排除的路径：** P（正常召回不合格），以及“看了测试再换核”。
- **最能推动判断的证据：** 表 C3（最宽带宽与未标准化的反例）和表 C2（两类召回与合格条件）。
- **是否需要整合全部探究问题？** 需要。备忘录必须引用 T1–T6。只看表 D1 的学生会被合格条件和冻结规则挡住，无法绕过前面的推理直接作答。

## 六、残余风险与建议

1. **自试填的局限。** 修订者熟悉题意，可能低估歧义。按技能的首选做法，还应让一个只看学生材料的新代理或真实学生再试填一次。以往经验是，新代理的 AI 试填倾向于少报歧义，所以复测时仍要做冷读指代审查。
2. **篇幅。** 学习单从21页增加到28页，其中阅读页、阅读指南和术语表约占4页。学生实际拿到的是分阶段发放的六份阶段版（9/3/3/6/5/2页），每次负担不大。
3. **如需压回120分钟，建议依次：**
   - 决策检验矩阵去掉第四列（约省2分钟）；
   - 证据卡改为课前统一提供原句（约省4分钟）；
   - Packet A 核对只保留“尺度、受试者独立、测试表现”三行（约省3分钟）；
   - 把概念辨析移到翻转课堂的教师综合环节（约省5分钟）。

   不建议删除表 C3 或 Q2 的支持向量识别，它们承担了本讲最关键的概念纠错。
4. **L 的正常召回恰好等于门槛（13/20=0.650）。** 这是真实数据的结果，不是人为设计。教师用书已把它列为追问点，提醒学生小分母的脆弱性。
5. **ISLR 与 scikit-learn 中 C 的方向相反。** 这是 AI 回答里常见的混淆，学习单和术语表都已提示，也可作为证据卡的范例。
